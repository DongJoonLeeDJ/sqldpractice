종합 문제 1

다음 설명 중 가장 올바른 것은?

① Entity는 실제 저장된 데이터이다.
② Attribute는 Entity를 설명하는 정보이다.
③ Domain은 테이블의 이름이다.
④ Instance는 속성(Attribute)의 다른 이름이다.
정답 : ②

① → Instance 설명
③ → Domain은 값의 범위와 규칙
④ → Instance와 Attribute는 전혀 다른 개념

종합 문제 2

회원관리 시스템에서 다음 중 Entity로 가장 적절한 것은?

① 회원
② 회원이름
③ 김철수
④ VARCHAR(30)
정답 : ① 회원

종합 문제 3

회원 이름은 최대 30자까지 입력 가능하다. 이 설명과 가장 관련 있는 것은?

① Entity
② Instance
③ Domain
④ Relationship
정답 : ③ Domain

시험 풀이 요령

문제를 읽을 때 ① 관리 대상인가? ↓ Entity ==================== ② 설명하는 정보인가? ↓ Attribute ==================== ③ 실제 데이터인가? ↓ Instance ==================== ④ 입력 규칙인가? ↓ Domain
★★★★★ 강사 팁 학생들에게 문제를 보자마자 키워드에 동그라미 치는 습관을 알려준다. 예) '관리 대상' → Entity '실제 저장' → Instance '속성' → Attribute '범위' '규칙' → Domain
★★★★★ SQLD는 암기 시험처럼 보이지만 문제의 키워드만 찾아도 절반 이상은 쉽게 풀 수 있다.
