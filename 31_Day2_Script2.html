SQLD Day2 — Script 2: 정규화

수업 목표

정규화를 암기표가 아니라 “중복 → 이상현상 → 종속 → 분리”의 흐름으로 이해시킨다.

0~15분 | 도입

강사: “수강 테이블에 학생 이름까지 같이 넣어 봅시다. 김철수라는 이름이 수강 과목마다 반복되겠죠?”

학생이 “중복된다”고 답하면 “중복되면 뭐가 문제일까요?”라고 한 단계 더 묻는다.

15~45분 | 이상현상

하나의 사례를 계속 유지한다. 학과명 변경 → 갱신 이상, 학생 없는 학과 등록 → 삽입 이상, 마지막 학생 삭제 → 삭제 이상.

갱신 이상 / 삽입 이상 / 삭제 이상

강사: “정규화는 이 문제를 줄이기 위해 데이터 구조를 다시 보는 과정입니다.”

45~75분 | 함수적 종속

강사: “학번을 알면 학생 이름을 알 수 있나요?”

학생: “네.”

강사: “그러면 학번이 이름을 결정한다고 볼 수 있습니다.”

학번 → 이름
학과번호 → 학과명

결정자와 종속 속성의 관계를 간단한 화살표로 판서한다.

75~110분 | 1NF / 2NF / 3NF / BCNF

1NF는 원자값, 2NF는 부분 함수적 종속 제거, 3NF는 이행적 함수적 종속 제거, BCNF는 결정자가 후보키가 되도록 강화한다.

강사 팁
“1,2,3을 외우세요”보다 “각 단계에서 어떤 문제가 없어지는가?”를 반복한다.

110~120분 | 퀴즈

복합키 문제 하나를 제시하고 부분 종속을 찾게 한다. 마지막 질문: “그럼 테이블을 무조건 계속 나누면 좋을까요?” → 다음 Script의 반정규화로 연결.
