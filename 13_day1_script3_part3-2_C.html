실제 데이터가 들어온다면?

강사

지금까지는 학생, 학번, 이름, 학과... 이런 항목만 있었습니다.

그런데 아직 진짜 학생은 없습니다.

그럼 실제 학생이 입학하면 어떻게 될까요?
학생 ────────────────────────── 학번 이름 학과 ────────────────────────── (아직 값이 없음)
학생들에게 "실제 데이터를 넣어볼까요?" 라고 말하며 함께 채워나간다.

학생 참여

학생들에게 실제 값을 말하게 한다.

예상 답변
  • 2026001
  • 홍길동
  • 컴퓨터공학과
학생 ────────────────────────── 학번 이름 학과 2026001 홍길동 컴퓨터공학과 ──────────────────────────
강사

좋습니다. 방금 입력한 것은 '학생'이라는 개념이 아니라, 실제로 존재하는 학생 한 명의 데이터입니다.

Instance 소개

강사 데이터베이스에서는 이렇게 실제 저장된 한 건의 데이터를 Instance(인스턴스) 라고 합니다.
학생 ↓ Entity ==================== 학번 이름 학과 ↓ Attribute ==================== 2026001 홍길동 컴퓨터공학과 ↓ Instance
학생들이 "한 줄" "한 사람" "데이터 한 건" 이라는 이미지를 갖도록 설명한다.

실무 용어 연결

강사 실무에서는 Instance라는 표현보다 다른 말을 더 많이 듣게 됩니다.
Instance = Row = Record = Tuple (상황에 따라 사용)
초급 과정에서는 "실제 데이터 한 건" 이라고만 기억해도 충분하다. Tuple은 이후 관계형 모델 설명 시 다시 등장한다고 예고만 한다.
